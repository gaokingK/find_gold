## 说明

这是第 4 天任务池，目标是在第一版接口手工验收通过后，补齐接口自动化测试能力。

执行原则仍然遵守 `AGENTS.md`：

## 本天的两条硬性要求

1. **测试只允许连 `fund_test_db`。** 任务 015 的 `clean_db` 会执行 `TRUNCATE`，一旦连到开发库 `fund_db`，开发数据会被清空。守卫必须在 `TRUNCATE` 之前生效。测试过程中如果出现任何指向 `fund_db` 的迹象，立即停止，先修守卫。
2. **数据库密码只通过环境变量传入**，不要写进任何会提交到 Git 的文件。

## 验收节奏

每完成一个任务，新手后端需要反馈：

1. 修改或新增的文件列表。
2. 验证命令和输出。
3. `pytest -q` 的完整输出（测试结果必须贴原文，不要只写「都通过了」）。
4. 遇到的问题。
5. 是否有未完成项。

只有任务验收通过后，才继续下一个任务。
