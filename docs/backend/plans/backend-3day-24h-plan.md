# 后端 3 天 / 24 小时任务计划

## 说明

这是任务池，不是让新手后端一次全部执行。

执行原则仍然遵守 `AGENTS.md`：

1. 按顺序推进。
2. 一个任务只引入少量新概念。
3. 每个任务完成后必须验证。
4. 上一任务未验收，不开始下一任务。

## 验收节奏

每完成一个任务，新手后端需要反馈：

1. 修改或新增的文件列表。
2. 验证命令和输出。
3. 遇到的问题。
4. 是否有未完成项。

只有任务验收通过后，才继续下一个任务。
