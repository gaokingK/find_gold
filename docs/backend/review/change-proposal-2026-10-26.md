## 一、接口文档补写（9 条全局约定，全部新增进 `v1-basic-management.md` 第 1 章）

| 编号 | 条款 | 不补的后果 |
| --- | --- | --- |
| 1.7 | 时区与日期基准：一律 Asia/Shanghai 本地时区，不用 UTC；`observe_days = DATEDIFF(今天, 观察开始日)`，开始日当天为 0 | 服务器跑 UTC 时，北京时间 08:00 前提交的"今天"操作被判成未来日期而拒绝 |
| 1.8 | 全局异常响应：非法 JSON / 404 路径 / 405 方法 / 500 一律返回 JSON，禁止 Flask 默认 HTML 错误页 | 前端 axios 拿到 HTML 字符串，解析直接崩 |
| 1.9 | 错误码总表（12 个码 + HTTP 映射 + 适用模块），全项目唯一，各模块只能引用不得自建 | 同名冲突返回 400 还是 409 靠猜；CSV 文件类错误无码可用，只能靠 message 文案区分 |
| 1.10 | 通用查询参数规则：分页越界返回空数组不报错；排序字段白名单**禁止拼进 SQL**；筛选类参数指向不存在资源返回空列表（200），写入类返回 404 | 分页越界三种实现并存；排序字段拼接 = SQL 注入 |
| 1.11 | 数值精度与序列化：一律 Decimal、四舍五入固定 `ROUND_HALF_UP`（不用 Python 默认的银行家舍入）；金额 2 位 / 份额 4 位 / 净值 4 位 / 比率 6 位；**JSON 不保留尾随零** | 净值小数位无定义，市值精度跟着飘；0.5 边界前后端算出的数不一样 |
| 1.12 | 文本字段规则：先 `strip()` 再校验和比较；唯一性不区分大小写；各字段长度上限 | 新手定义 `VARCHAR(20)`，长基金名被静默截断；`" 基金小星 "` 和 `"基金小星"` 被当成两个博主 |
| 1.13 | CORS：`flask-cors`，允许 `http://localhost:5173`，方法 GET/POST/PUT/DELETE/OPTIONS | 前端所有请求被浏览器拦掉，新手会误以为接口写错 |
| 1.14 | `code` 字段类型：成功是数字 `0`，失败是字符串错误码 | 前端 TS 类型定义无从下手 |
| 1.15 | `details` 元素结构：`{field, message, row?}`，row 从 1 开始不含表头；多字段一次性返回全部错误不短路；批量导入最多返回前 50 条 + `error_count` | 用户改一个字段提交一次才看到下一个错；导入 1000 行全错返回一个巨大 JSON |

## 三、修 3 处必现 bug 级遗漏

1. **编辑接口唯一校验必须排除自身**（`WHERE name = ? AND blogger_id != ?`）——不排除的话，只改板块不改名称点保存就报名称重复，编辑功能直接不可用。涉及博主/基金/初始持仓三个编辑接口。
2. **`observe_start_date` 不能晚于今天**——否则 `observe_days` 为负，前端显示"-5 天"。
3. **派生字段排序的 SQL 映射**——`observe_days` 不落库，必须用 `DATEDIFF(CURDATE(), observe_start_date)` 排序，不能在 Python 里排（那样分页是错的）。

### 4.1 两处「执行即死」的硬伤（必须改，照抄必然报错）

### 4.2 最大的风险：第 8、9 天测试保障整体消失

001–022 每个接口都有配套测试，**033–039 七个接口一个测试都没有**，完成标准只有一句「`pytest -q` 全部通过」——这只证明没改坏旧的，证明不了新写的对。成本 ≤0 返回 null、缺净值返回 null、超额卖出照实返回负数，现在全靠手工 curl。这是系统里数字最密的部分，零回归保护不可接受。

### 4.5 其余修订项

- **`round(float(value), n)` 与已定口径冲突**：031/034/036/037/038/039 六份都这么写，但 Python 的 `round` 走 `ROUND_HALF_EVEN`（银行家舍入），与 1.11 要求的 `ROUND_HALF_UP` 不符，且用了 float。建议 031 定一个标准实现，其余五份照抄。
- **执行目录两套**：019–028、033–040 用 `/mnt/d/...`（WSL），029–032 用 `/d/...`（Git Bash）。新手做到第 7 天 `cd` 会失败。统一到 `/mnt/d/`。
- **`app/services/` 目录没建**：030/033 要往里放文件，但没有任何任务写 `mkdir -p app/services` + `touch __init__.py`（002/003 建 routes、utils 时都明确给了这两条命令）。
- **backlog 那条「金额统一用 Decimal，第 8 天前必须完成」建议降级 P3**。判据：020 的 `float()` 只在解析入参和序列化两处，库里是 DECIMAL，030/033 全程 Decimal，累加链路没有一环经过 float，「几十笔累加对不上账」当前不成立。改成在 040 验收清单加一条检查项即可。
