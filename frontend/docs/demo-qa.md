# Demo QA

## Automated checks

- `npm ci`
- `npm run test:unit`
- `npm run build`

The final verification result is recorded after the clean install and full test/build commands are run.

## Scope notes

The demo uses deterministic local mock data. It does not connect to Flask, MySQL, Umi-OCR, 天天基金, 蛋卷, or a real NAV service. Screenshot previews are intentionally represented by file names.
